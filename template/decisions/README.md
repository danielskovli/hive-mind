# Decisions

One file per choice between alternatives for how your sessions, this hive or your tracker work:
`YYYY-MM-DD-<slug>.md`, with a title, then **Context**, **Decision**, **Why** and **Ruled out**. Sessions
write them as the core's `instructions/hive.md` says, and never rewrite one: a later decision supersedes
it by saying so. The automatic tidy logs what it did in `tidy/<date>.md`, and each retro writes
`<date>-retro.md`.
